# اسپرسو — Espresso Web App (v1.1.1)

وب‌اپلیکیشن یادگیری ایتالیایی سطح **A1 و A2** (هم‌راستا با کتاب Nuovo Espresso) با رابط فارسی، فلش‌کارت، آزمون، تلفظ و پشتیبانی آفلاین (PWA).

## 🌐 نمایش زنده (GitHub Pages)

اپلیکیشن به‌صورت دائمی روی GitHub Pages منتشر می‌شود:

**https://kasramoh030.github.io/Espresso-v.1.0.0/**

هر بار که تغییرات روی شاخهٔ `main` push شود، گردش کار
`.github/workflows/deploy-pages.yml` سایت را به‌طور خودکار بازنشر می‌کند.

## نسخهٔ ۱.۱.۱ (single-file-offline، ۲۰۲۶-۱۱-۲۳)

- کل اپلیکیشن در یک فایل `index.html` ادغام شده است (CSS، JS، دادهٔ درس‌ها و فونت‌های وزیرمتن به‌صورت inline/base64).
- پوشش محتوا از A1 به **A1 + A2** گسترش یافته است.
- `sw.js` با نسخهٔ کش جدید (`espresso-a1a2-v111-1`) جایگزین شده تا کاربران نسخه‌های قبل، به‌روزرسانی را خودکار دریافت کنند و کش قدیمی پاک شود.
- `manifest.webmanifest` برای نصب‌پذیری PWA حفظ و به‌روزرسانی شده است (آیکون‌ها از `icons/`).

## ساختار

| مسیر | توضیح |
| --- | --- |
| `index.html` | کل اپلیکیشن (تک‌فایل، خودبسنده، RTL فارسی) |
| `sw.js` | سرویس‌ورکر برای کارکرد آفلاین و به‌روزرسانی خودکار |
| `manifest.webmanifest` | مانیفست PWA (نصب روی گوشی/دسکتاپ) |
| `icons/` | آیکون‌های PWA |
| `.github/workflows/deploy-pages.yml` | انتشار خودکار روی GitHub Pages |

## اجرای محلی

یک سرور ایستا کافی است:

```bash
python3 -m http.server 8000
# سپس http://localhost:8000 را باز کنید
```
